问题 3 证书离线计算包（偏离 1 天的出发日组合，指派 1、2，共 1100 个任务）

不需要安装任何软件；整个文件夹拷到服务器任意位置（路径最好不含空格），例如 D:\cert_offline。

步骤
1. 防止中断：控制面板关闭睡眠；暂停 Windows 更新的自动重启（或管理员命令行 powercfg /change standby-timeout-ac 0）。
2. 自检：双击 1_selftest.bat（约 5–15 分钟）。最后一行应为 “TOTAL REPLAYS 367865 OK”。
   若显示 MISMATCH 或报错，停下，把窗口内容拍照/复制带回。
3. 正式运行：双击 2_run.bat（默认进程数 = 逻辑核数 − 1，最多 60）。
   也可在命令行指定，例如 2_run.bat 40。窗口无输出是正常的，日志写在 job\work.log。
4. 看进度：双击 3_progress.bat，或打开 job\work.log 看最后几行（每完成一个任务一行，含“剩余约 x h”）。
5. 可以随时关窗口停止，再双击 2_run.bat 续跑（已完成的任务自动跳过，最多损失正在跑的任务）。
6. 带回：把整个 job\out 文件夹和 job\work.log 拷回（跑一半也可以带回，本机能合并已完成的部分）。
   放到本机 results\F\p3_cert4\out\ 下，Claude 运行 merge。

说明
- 每个任务约 100 万次回放；单进程约每小时 120 万次（本机实测，因 CPU 而异）。总量约 9.2 亿次，约 765 核时。
- 内存每进程约 150 MB。
