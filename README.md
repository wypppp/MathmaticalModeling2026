# MathematicalModeling2026

单人 + 双模型（Claude、ChatGPT）数学建模协作仓库。协作规则见 [AGENTS.md](AGENTS.md)。

## 目录

| 路径 | 用途 | 谁写 |
|---|---|---|
| `AGENTS.md` / `CLAUDE.md` | 协作规则（两个模型自动读取） | 人 |
| `spec.md` | 问题规格书（带原文出处） | 人确认后合并 |
| `state.md` | 当前阶段、角色、决策记录、失误台账 | 所有人 |
| `evidence.md` | 检验标准、实验记录、论文数字溯源 | 主工程方 |
| `problem/<题号>/original/` | 原题原件（权威版本） | — |
| `problem/<题号>/*.md` | 转换稿（PDF 提取可能丢下标/公式） | — |
| `notes/` | 人的独立笔记 | 人 |
| `src/` | 主工程代码 | 主工程方 |
| `review/` | 审查、独立规格书、独立复算 | 审查方 / 独立阶段 |
| `results/` | 代码输出（论文数字唯一来源） | 主工程方 |
| `paper/` | 论文稿 | 主工程方起草，人终审 |

## 流程（G0–G6）

| 关卡 | 内容 | 通过条件 |
|---|---|---|
| G0 读题 | 人先独立读；两模型背靠背写规格书 | 三份理解 + 分歧清单 |
| G1 题意守恒 | 双向追溯、反例检查、反向翻译（辅助） | `spec.md` 冻结，重大歧义已处理 |
| G2 结构与路线 | 特殊结构/极限情况；宽列方向，选基线、主路线、挑战路线 | 路线写入 `state.md` |
| G3 原型 | 最小可运行原型、独立检查器、数据来源登记 | 核心测试通过；时间过半前必须有基线结果 |
| G4 复算 | 审查方从 `spec.md` 独立复算核心结果 | 差异已解释 |
| G5 创新与有效性 | 敏感性、消融、异常机制 | 创新有对照证据，否则降低表述 |
| G6 论文 | 整合；摘要人写；数字与文献逐一溯源 | 留足排版与提交缓冲 |
