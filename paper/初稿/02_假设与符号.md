# 三、模型假设

题面已有明确规定的不再列出。以下是题面未规定或有解释空间、由本文补充的假设；标“★”的做了灵敏度分析（第十章）。

| # | 假设 | 理由 |
|---|---|---|
| H1 | 需求块（原批次、外部仓库、方向、存放仓库相同的货物行）整体转移，不拆分数量；统筹时不改存放仓库 | 货物有确定的来源和去处；拆分数量会产生题目未规定的新批次 |
| H2 | 运力 T = ⌈max(接领等效车数之和, 送交等效车数之和)⌉ | 题面只定义了“最少运输车辆数”；该式复现了三张附件表中全部 105 个批次的表列运力 |
| H3★ | 保障车：T ≤ 20 时 1 台，T ≥ 21 时 2 台 | 附件 3 中 T ≤ 19 为 1 台、T ≥ 26 为 2 台，20–25 无样本，分界只能自定 |
| H4★ | 单批总里程 ≤ 2000 km 当硬约束 | 原文“一般不超过”；三张附件表的批次都满足 |
| H5 | “自身队属货物仓库”取执行单位可使用的全部队属仓库 | 附表 1 分“所属”“可使用”两栏，术语 5 未区分；可使用的仓库对该单位同样是自家仓库 |
| H6 | 就便情形中的“Ux 的目标货物仓库”取该批次保留的自有货物所到的仓库 | 防止用代领来的仓库再去顺带，与“目标货物仓库数量不增加”一致 |
| H7★ | 一段路当天到不了下一站就次日 8:00 出发；超过 500 km 的路段只在 8:00 出发、途中过夜 | 录 3.4“剩余工作时间无法到达下一任务地点……则次日进行机动”，并且实际中宜在定点场所休息；超过 500 km 的路段当天必然到不了，按同一句字面次日 8:00 出发 |
| H8★ | 一站内装、卸分别按等效车数向上取整后相加计时 | 原文“非满载车辆按满载车辆计算”，未规定取整层级 |
| H9★ | 留置的车也受“最多等待 1 天”限制 | 原文称“留置等待” |
| H10★ | 路线由作业站依次组成，相邻两站的里程取附件 1 的表列值，不借第三点中转来缩短（附件 1 中 44.7% 的节点对表列值大于经第三点中转的和，见 1.2 节）；同一作业站至多到访 2 次 | 件 7 注 2“依次填入经过的货物仓库直至回到驻地”；代领⑤原文就要求“增加访问 Uy 的队属货物仓库”，故须允许重复到访 |
| H11 | 代领③中货主自取的行程不计入任何批次 | 原文只写“可进行代领”，未说明货主如何取回；第九章报告自取的货量与往返里程 |
| H12 | 代领④的“之后”取整批先后：货主批次的出发日晚于暂存批次回到驻地的日期 | “实施时间”在术语 11 中定义为时间段；按最严格的读法排出的方案在较宽读法下同样合规 |
| H13 | 问题 2 按字典序：先使 U9 交给 U6 的块最多，再批次最少，再代领代交量最少，再提报时段冲突最少；仍并列时取问题 3 合成目标最小的指派 | 原题未规定批次数与代领代交量如何平衡；另给出两者的折衷曲线。四级之后有 3 个并列最优，它们对问题 3 的影响不同，问题 3 又以问题 2 的计划为输入（题“针对问题 2 得到的货物调运计划”），故以问题 3 的目标作第 5 级 |
