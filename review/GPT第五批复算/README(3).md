## 问题 3 的排序证书

1. 固定附件 6 指派和装卸端点，块可独立选择首次或第二次到访时装卸。按直达里程行驶，只允许在装货站留置全部车载货，按逆序汇合。独立 DFS 产生 1208 条逐批路线（32 批合计，含孤立 S10 放松项）。其中 381 条满足同端点同处理且通过孤立回放。这个数统计带装卸与留置决策的轨迹，不要求与正文候选去重数相同。
2. 精确距离用有理数、时间用整数。令 $w=(u_L-l_L)/8$，固定偏离后比较 $w\tau+\bar L$。全体块级路线逐批取孤立 $w\tau+\bar L$ 的最小值再求和，给出时间、距离两项归一化之和至少 **0.155492422832**。因此偏离至少 7 时，$z\ge 1.555492422832>1.406160918288$。单算 $7/5=1.4$ 无法完成这一步。偏离 6 的全局孤立和也不足以一概排除，以下逐向量加入实际排队。
3. 用各批最短孤立天数检查季度及出发窗、同单位并发、R4 原批 7→27、13→25 整批先后。在总偏离不超过 6 的整数日期空间内，0–4 天均无解，5 天有 4 个向量，6 天有 232 个。5 天的四种只改变原批 13、25 的出发日序，分别为 (9,15)、(10,16)、(11,17)、(12,18)，4 月 1 日为第 1 天。[全部 236 个向量](Q3_departures.csv)
4. 对每个向量，先扣去其余批的孤立代价下界，由剩余预算上界确定候选路线可占用的最大天数。各站可服务日期保守覆盖从出发至这一最晚日的**整段**区间。可能在同一仓同一天作业的批次连边，逐个连通分量枚举并回放。分量间没有可影响达标方案的仓日冲突。先解较小分量，以其精确最小代价收紧其余预算，再划分。分量内部用孤立代价和剪枝；没有用删去其他车队后的局部排队时间剪枝。跨分量的单位并发可暂时放松，最终见证整套回放再核验。相同站序、逐站工时及留置区间的路线，保留载货距离最小、再比里程最小者，因其排队行为一致。S9 同到按批号，搜索按出发日、原批号顺序编号，没有把重排批号作为决策。
5. 偏离 6 的 232 个向量全部排除。偏离 5 的向量 1、4 也不能达到主分。向量 2、3 的最小分均为 **1.406160918288**，V 均为 **11**，同分最短总里程均为 **30729 km**。见证逐批保留精确均距与作业掩码，整套回放满足全部约束。两套见证都满足同端点同处理。扩大到块级后，严格更低的分数、同分更小的 V 和前两项相同但更短的里程均不存在。[逐向量判定](Q3_optimality.csv) · [并列见证](Q3_optimal_witness.csv) · [作业位序](Q3_route_jobs.csv)

## 复现

在上述主分支提交的工作树中放入本目录，并保留同树下的 `review/gpt_v23c/Q{3,4}_blocks.csv`。需要 Python 3.9+、openpyxl，以及支持 128 位整数的 C++17 编译器。以下命令在本目录执行。

```sh
python check.py
g++ -O3 -std=c++17 routes.cpp -o routes
python optimal.py
python lower.py
```

Windows 可编译为 `routes.exe`，或用环境变量 `F_ROUTES` 指向编译好的程序。程序读取附件 1、4、5、四份结果工作簿、公开基线两份 CSV；既有 GPT 块表只用于跨版本对照。路线掩码节点 0 为驻地，其后为本批可用队属仓与作业端点并集按站名排序。每步依次编码节点、装、卸、留置的位掩码。两个 findings 文件保留表头，零条数据行表示硬约束检查未发现违规。
