## 0. 先说清楚能做到什么

- 机器**证明不了**“模型忠于原题”。能机器化的只有三件事：①追溯是否完整；②与出题人自己给的数据是否一致；③结论对备选读法是否稳健。语义上“这句话该怎么读”，仍然要靠人和局外模型。
- 现状：`evidence.md` 的 R1–R15 验证层全是 B 或 C，**没有一条 A**。已有但没被登记成 A 的证据：V2、V3（运力、人数公式复现 105 批表列值）、R9/R10（附件 3 的 16 笔转移全部能用 R1–R8 表达）——这两条本质上是“用出题人数据当裁判”。
- 论文里 A 层的措辞上限：“原题条款覆盖完整；与题给数据的不符之处已逐项解释；主要结论对备选读法稳健（或：在读法 X 下变为 Y）”。**不写“已验证忠实于原题”。**
- spec v2.2 已冻结：本方案的发现只进新的裁决单，不直接改 spec 或 src 的主结果。
