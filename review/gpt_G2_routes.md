## 二、七个候选方向

| 方向                       | 适用问与价值                                                                                            | 局限与采纳条件                                                                                       |
| -------------------------- | ------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------- |
| 1. 守恒对账与反事实复算    | P1。对同一张表分别使用历史计数和统一计数，可分离“计划改变”与“计数改变”。                            | 数量守恒不能唯一还原两条同质记录的身份。保留未唯一匹配的记录，给出其对汇总的影响。采为 P1 主路线。   |
| 2. 确定性贪心与单步改进    | P2、P4 的低成本参照。每次比较完整可行方案，用原问题的目标排序，可检验复杂模型是否只获得显而易见的改进。 | 若改进需要两个决策同时改变，单步搜索会停住。使用固定平局规则，报告起点与终点。                       |
| 3. 分层整数优化            | P2。离散选择和分级目标可以分别给出上下界，对“至少需要多少批”的结论最有说服力。                        | 简化模型的最优解可能不满足冻结规格。下界可来自放松，可行上界必须覆盖全部适用硬约束。采为 P2 主路线。 |
| 4. 独立事件回放            | P1、P3、P4。把计划转换为到达、服务、等待、跨日和返回事件，统一核算历史风险与新方案指标。                | 回放能确认一份给定方案的结果，单次失败不能证明该分配无解。作为共用评估工具。                         |
| 5. 有限候选计划的精确选择  | P3。固定分配下比较多组完整的路线与日历决策，保留基线候选，联合评价共享资源影响。                        | 有限池最优只对该池成立。预先独立算出的单批耗时可能因排队改变，最终值以全局回放为准。采为 P3 主路线。 |
| 6. ε 约束与非支配方案比较 | P2、P4。允许某指标退让一个可解释的整数单位，观察其他指标能换来多少。可发现加权和碰不到的离散折点。      | 端点或网格过疏会遗漏折点。只将确证最优的点称为精确前沿，限时结果称为已发现的非支配集。               |
| 7. 联合邻域搜索            | P4。允许分配和排程一起变化，检验固定分配对结果的限制。适合提供整例可行上界。                            | 对搜索预算与起点敏感，且无天然最优性证书。以相同预算、多起点的可行率和得分分布评价。                 |

## 四、多目标合成与均衡性

**P2 采用冻结的字典序。** 依次最小化批次数 B、按接手单位车型折算的代办量 A、允许出发窗不相交的不同原批次与执行批次对数 V⁰。每层固定上一层的已证最优值。若上一层只有可行上界，后层结果必须注明以该批次数为条件。另逐整数扫描 B≤b 时的最小 A；多允许一批节省的等效车数就是相邻折点的代价。不得把真实排程提前施加给 P2。

**P3 采用归一化最大遗憾。** 三个主指标分别取全体批次的载货平均距离之和 L、占用自然日数之和 T、开始偏离天数之和 Δ。对预先确定且含强基线的标定方案集，记录每项最小值 l 与最大值 u，并冻结同一套标尺。对 u>l 取 z=(f−l)/(u−l)；若 u=l，以该项的一个报告单位作分母（1 km 或 1 天）。新方案超出标定区间时保留实际值。按 (max z, Σz, V) 字典序取小，默认三个主指标同权。最大项防止某一维严重恶化，总和打破并列，V 最后比较。报告各项原始值以及调运总里程，避免把 L 误算成车公里。对每个主指标轮流加倍权重再选一次，披露首选方案是否改变。

**P4 保留批次预算的物理含义。** 先在 B≤b 内比较 (L,T,Δ,E,W)，其中 E 为下述失衡值，W 为批次目标仓库对数。用 P3 同样的最大遗憾与总和规则选择，五项默认同权；共同指标沿用冻结尺度，新增两项用同法标定。主表以可行 P3 的 B 为预算，使同一条件下的比较有直接解释；再按整数改变预算，给出 B 与其他指标的折衷。若 P3 尚无可行解，采用 P4 已找到的最小可行批数作暂定预算，标注 P3 对照缺失。A、总车数、总人数、指挥车队总里程随每个代表解一并报告，附表 4 共十项。若一个方案在六个 P4 目标上被另一可行方案支配，剔除前者。主表列 P3、P4、绝对差；基值非零时补百分比。

**均衡性按互助双方的净负担计算。** 定义 12×12 有向矩阵 F，Fᵢⱼ 表示单位 i 替单位 j 承担的等效车数，按 i 的车型折算，对角为零。R4 的代办份额只记一次。记 Hᵢ=ΣⱼFᵢⱼ 为助人量，Rᵢ=ΣⱼFⱼᵢ 为受助量，A=ΣᵢHᵢ=ΣᵢRᵢ。附表取下式，越小越均衡：

    E = Σᵢ |Hᵢ − Rᵢ| / (2A)    当 A > 0
    E = 0                       当 A = 0

净流入与净流出的总量相等，故 E 在 [0,1] 内，可解释为未被本单位受助量抵消的助人份额。甲替乙承担 3 辆、乙替甲承担 1 辆时，A=4、E=0.5。双方各承担 3 辆时 E=0，即使其余十家都未参与。这个边界体现本稿选择衡量收支对等；规模集中度由正文的矩阵及各单位 H、R 两列揭示。无互助时同时标 A=0。新增互相代办会扩大分母，故同时披露 A 与未抵消量 AE；若五项得分及批数完全相同，优先选 A 小者。

## 五、哪些结论值得写进正文

1. **先算基线，再解释提升。** 所有算法用同一精度和检查器，先比硬可行性，再比原始目标、综合排序和耗时。某方法仅找到可行解时只报上界。与已优基线打平就是打平。
2. **用结构下界校验数值。** P2 的批次下界证书要覆盖所有允许情形，含内部互转反向；不能用单块等效量大于 3 预删候选。P3 的仓库服务日下界可由该仓总作业台次除以 20 向上取整得到，仅用于校验对应仓库的服务日数。L8 中具体仓库的下界须以对应方案和取整口径复算。
3. **控制每次消融所改动的条件。** R4 纳入主结果，另做关闭 R4 的整链对照，逐笔登记暂存天数。对重复到访、留置分别开关，以同一分配比较 L、里程、占用天数和可行性。登记 L1 的单例即使复现，也只能说明该例的效果；全局队列与到达时刻仍可能改变结论。
4. **区分指标自身造成的下降。** 若两批货的批内平均距离分别为 p、q，且合批时每组的载货路程和等效量均保持不变，新指标是 p、q 的加权平均，原指标则为 p+q。即使实际货物行程毫无改善，指标也能下降。因此 P4 除主表外宜并列同批数结果与辅助车公里数，解释 L2 所指的效应。
