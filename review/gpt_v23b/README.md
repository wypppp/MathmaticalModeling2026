## 两项补充实验

**1. 禁用代领③后，问题2最少需要33批，与 r3_study.csv 一致。** 从附件4重建90块、46个候选执行批，为每块选自办或跨单位代办。用CP-SAT求一个放松模型的下界：保留自有目标支持、车型运力限制及U9优先级，省略里程，放宽R4/R5的部分依赖，运力系数向下截断。模型不提供R3选项。先解得U9转U6最多5块，固定5块再最小化批数，求解状态 OPTIMAL，下界为33。

上界可由已核对的32批方案直接构造。其唯一R3是块11。恢复该块的原批6自行执行，同时从原批17去掉这笔代办，保留其自有块30。两个批次均只去 WE 领货，回各自存放仓；重算运输车数分别为1、5，闭合里程196、268公里，其余指派和U9优先值保持。由此得到可行33批。上下界相等，只就所抽查的最少批次数作结论。

**2. 固定问题2指派，不允许提前出发时，问题3不可行，与 p3_ablation.csv 一致。** 此次选择该文件的“不允许提前出发”行。根据工作簿中的R4块43，原批13需先回驻地，原批25方可出发。原批13的允许节点是 U6、WP、WA、WG，至少要访问 WA 和 WG 后回到 U6。即使允许对这些节点取最短路、免除 WP 必停，闭合行驶仍至少1,067公里。按实际货量和执行方车型对必须装卸的作业分向取整，至少58车次。共需至少 1,067/62.5 + 58/2.5 = **40.272小时**，占用至少6个自然日。若4月14日才出发，领回批最早4月20日可出发，超过其4月18日的硬上限。该矛盾对更换路线或排队次序仍成立。
