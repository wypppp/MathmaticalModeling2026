
基于 `spec.md`（v2 冻结版 + G2 裁决）与 `数据结构说明.md`，在**完全不接触实现代码**的黑盒视角下，设计 **22 个测试用例（T01–T22）**：

- **边界情形（7 个：T01–T07）**：SOC 上下限、充放电功率上限、时段索引与标签修正、6/12/18 时锁定边界、跨午夜/跨月连续性、12-31 年末滚动视界、附件 3 预报拼接与线性积分。
- **退化与解析基准（8 个：T08–T15）**：恒定电价零套利、$1/0.81$ 效率阈值与不售电截断、$S(0:00)$ 自由 vs 固定 6000、Q2 80% 报童分位数、Q3 不调整区间 $[F^{-1}(0.7), F^{-1}(0.9)]$ 与读法 A/B、Q3 组合结算与 D9 一次结算、零不确定性退化、Q4 联合分布价格加权分位数。
- **对抗与不变性检验（7 个：T16–T22）**：因果性双路径对照、弃光零对偶价下的伪同时充放对抗、Q4 突发高电价当期响应与防偷看、反硬编码“周末=周六日”的周型切换、当天前缀实测修正对抗、Q4 合并紧急购电表逐时段计价、全局物理/账目守恒与输出表结构一致性。

> **通用换算约定**（除非用例另有说明）：每时段 $\Delta t = 1/6\text{ h}$（10 分钟）；电量（kWh）$=$ 功率（kW）$/ 6$；充放电功率上限 $5000\text{ kW} \Rightarrow c_t, d_t \le 2500/3 \approx 833.3333\text{ kWh}$；SOC 范围 $[1200, 10800]\text{ kWh}$；递推 $S_{t+1} = S_t + 0.9c_t - d_t/0.9$。

## 一、边界情形（T01–T07）

### T01：SOC 下限恰好触及 1200 kWh 与放电功率上限截断

- **测试目标**：验证单向放电效率除以 $0.9$（$S_{t+1} = S_t - d_t/0.9$）、功率上限 $2500/3\text{ kWh}$、SOC 下限 $1200\text{ kWh}$ 的先后截断逻辑以及紧急购电兜底计算。
- **输入**（简化 2 时段，$t=1,2$）：

  - 初始 $S_1 = 2200\text{ kWh}$，计划购电 $b_1 = b_2 = 0$，实际光伏 $G_1 = G_2 = 0$，电价 $p_1 = p_2 = 1.0\text{ 元/kWh}$。
  - 实际负载：$t=1$ 为 $6000\text{ kW}$（$L_1 = 1000\text{ kWh}$）；$t=2$ 为 $3000\text{ kW}$（$L_2 = 500\text{ kWh}$）。
  - 策略：缺口时优先尽量放电以减少 $5p$ 紧急购电。
- **期望输出 / 可核查性质**：

  1. **$t=1$（功率上限先触发）**：SOC 允许最大母线放电 $0.9\times(2200-1200)=900\text{ kWh} > 2500/3\text{ kWh}$，受功率上限约束 $d_1 = 2500/3 \approx 833.3333\text{ kWh}$，$c_1 = 0$。
  2. $S_2 = 2200 - (2500/3)/0.9 = 34400/27 \approx 1274.0741\text{ kWh}$；$e_1 = 1000 - 2500/3 = 500/3 \approx 166.6667\text{ kWh}$。
  3. **$t=2$（SOC 下限先触发）**：SOC 允许最大母线放电 $0.9\times(34400/27 - 1200) = 200/3 \approx 66.6667\text{ kWh} < 2500/3\text{ kWh}$，因此 $d_2 = 200/3\text{ kWh}$，$c_2 = 0$。
  4. $S_3 = 1200.0000\text{ kWh}$（精确等于下限，绝不低于 $1200$）；$e_2 = 500 - 200/3 = 1300/3 \approx 433.3333\text{ kWh}$。
  5. 若追加 $t=3$ 且 $S_3 = 1200$、缺口 $>0$，必有 $d_3 = 0$；总紧急购电费 $= 5\times 1.0\times(500/3 + 1300/3) = 3000.00\text{ 元}$。

  - **防错点**：若误用 $S_{t+1} = S_t - 0.9 d_t$ 或 $S_t - d_t$，会导致 $S_3$ 穿仓或少算紧急购电 $e_2$。

### T02：SOC 上限 10800 截断与电池已满时富余电量无收益弃用

- **测试目标**：验证单向充电效率乘以 $0.9$、SOC 上限 $10800\text{ kWh}$、电池满/功率满时富余电量的单独计量与全额计费规则（§3.2 Step 5）。
- **输入**（简化 2 时段，$t=1,2$）：
  - 初始 $S_1 = 10000\text{ kWh}$，电价 $p_1 = p_2 = 0.5\text{ 元/kWh}$（Q2 结算）。
  - 锁定计划购电 $b_1 = 1000\text{ kWh}, b_2 = 300\text{ kWh}$；实际 $G_1 = G_2 = 100\text{ kWh}$，$L_1 = L_2 = 100\text{ kWh}$。
  - 策略：富余时尽量充电吸收多余电量（后续预期仍有负荷）。
- **期望输出 / 可核查性质**：
  1. **$t=1$（充电功率上限先触发）**：净富余 $1000\text{ kWh}$，SOC 可吸收空间 $(10800-10000)/0.9 = 8000/9 \approx 888.8889\text{ kWh} > 2500/3\text{ kWh}$，故 $c_1 = 2500/3 \approx 833.3333\text{ kWh}, d_1 = 0$。
  2. $S_2 = 10000 + 0.9\times(2500/3) = 10750\text{ kWh}$；弃用富余 $\text{surplus}_1 = 1000 - 2500/3 = 500/3 \approx 166.6667\text{ kWh}$，$e_1 = 0$。
  3. **$t=2$（SOC 上限先触发）**：SOC 可吸收空间 $(10800-10750)/0.9 = 500/9 \approx 55.5556\text{ kWh}$，故 $c_2 = 500/9\text{ kWh}, d_2 = 0$，$S_3 = 10800.0000\text{ kWh}$（绝不超过 $10800$）。
  4. $\text{surplus}_2 = 300 - 500/9 = 2200/9 \approx 244.4444\text{ kWh}$，$e_2 = 0$。
  5. 总富余弃电量 $= 3700/9 \approx 411.1111\text{ kWh}$ 单独报告；计划电费仍全额计收 $0.5\times(1000+300) = 650.00\text{ 元}$，不得因富余或售电扣减费用。

### T03：自然日时段映射（`00:10`–`0:00+1`）与标签 / 表 1 抽样纠偏（D1）

- **测试目标**：验证附件区间末时标到自然日 `[0:00, 24:00)` 144 个时段的映射、输出模板标签修正及论文表 1 抽样点对齐。
- **输入**：构造一个与 `附件1.xlsx` 格式完全一致的 144 行输入：
  - 第 $i$ 行（$i=1,\dots,144$，时标依次为 `00:10:00` 到 `0:00+1`）设置：电价 $=0.5\text{ 元/kWh}$，光伏 $=0\text{ kW}$，小区负载 $= 6i\text{ kW}$（即第 $i$ 个自然 10 分钟时段用能恰好为 $i\text{ kWh}$）。
  - 其中：附件行 `10:00:00` 为 $i=60$（负载 $360\text{ kW}=60\text{ kWh}$）；附件行 `10:10:00` 为 $i=61$（负载 $366\text{ kW}=61\text{ kWh}$）；附件行 `0:00+1` 为 $i=144$（负载 $864\text{ kW}=144\text{ kWh}$）。
- **期望输出 / 可核查性质**：
  1. `result1.xlsx`「计划购电量」共 144 条数据行：第 1 行时段标签修正为 `"0:00-0:10"`（不得为 `"0:10-0:20"`），$q_1 = 1.0\text{ kWh}$；第 144 行时段标签修正为 `"23:50-24:00"`（不得为 `"0:00+1-0:10+1"`），$q_{144} = 144.0\text{ kWh}$。
  2. 全日总购电 $\sum_{i=1}^{144} q_i = 10440.0\text{ kWh}$。
  3. 论文表 1 按自然时段 `"10:00-10:10"` 抽样取数时，取到的必为第 61 个位置（$q_{61} = 61.0\text{ kWh}$，对应附件 `10:10:00` 读数），而非第 60 个位置（$60.0\text{ kWh}$）。

### T04：Q3 在 06:00 / 12:00 / 18:00 的锁定与更新边界（防 off-by-one）

- **测试目标**：验证 3 个日内更新时刻对“已执行/尚未执行”时段的精确切分（`5:50-6:00` 属已执行，不可追溯修改；`6:00-6:10` 为首个可调整时段，其余同理）。
- **输入**（144 时段 Q3 单日测试）：
  - 0:00 预报全天无光伏，0:00 计划 $q_t = 100\text{ kWh}$ 对所有 $t=1,\dots,144$。
  - 6:00 前各时段（$t=1\dots 36$，即 `0:00-6:00`）实际 $G_t=0, L_t=100\text{ kWh}$。
  - 在 06:00 发布的新预报中，光伏骤增至 $600\text{ kW}$（且假设包含一个“倒推修改”或极端扰动使优化器有强烈动机调低包含 `5:50-6:00` 在内的购电量）；同理在 12:00、18:00 分别引入仅从该时刻起出现的光伏/负载分布剧变。
- **期望输出 / 可核查性质**：
  1. 06:00 修订后，第 1–36 时段（含 `5:50-6:00` 即 $t=36$）的 $a_t$ **严格锁定等于 $q_t$**；首个允许变动位置为 $t=37$（`6:00-6:10`）。
  2. 12:00 修订后，第 1–72 时段（含 `11:50-12:00` 即 $t=72$）保持 12:00 前的锁定值不变；首个允许变动位置为 $t=73$（`12:00-12:10`）。
  3. 18:00 修订后，第 1–108 时段（含 `17:50-18:00` 即 $t=108$）保持不变；首个允许变动位置为 $t=109$（`18:00-18:10`）。

### T05：跨午夜与 1 月 $\to$ 2 月 SOC 连续传递（D11 / D13）

- **测试目标**：验证 Q2–Q4 不施加日循环约束、跨日 SOC 连续传递、1 月仿真结果向 2 月 1 日的衔接以及输出起止日期口径。
- **输入**：从 `2025-01-01 0:00`（$S = 6000\text{ kWh}$）开始按主路线因果仿真至 `2025-12-31`。在 `2025-01-31` 构造低电价/高光伏晚间（使系统自然结束时 $S(\text{2025-01-31 24:00}) \ne 6000$，例如 $8500\text{ kWh}$），而 `2025-02-01` 紧接一个高负荷日。
- **期望输出 / 可核查性质**：
  1. 主口径下，`2025-02-01 0:00` 的初始 SOC 严格等于 `2025-01-31 24:00` 的末时刻 SOC（例如 $8500\text{ kWh}$），不得被重置回 $6000\text{ kWh}$ 或强行拉回至固定锚点。
  2. 对全期任意相邻两日 $d-1 \to d$，均有 $|S_{d,0} - S_{d-1,144}| < 10^{-6}$。
  3. `result2` / `result3` / `result4-2` / `result4-3` 的「计划购电量」表恰好包含 **334 个数据行**（`2025-02-01` 至 `2025-12-31`），不含 1 月份行且无缺漏日期。

### T06：`2025-12-31` 年末跨年滚动视界安全性（H2）

- **测试目标**：验证年末最后一天执行“滚动视界延伸到次日早上约 30 小时”（H2）时，不会因缺少 `2026-01-01` 实测数据而崩溃或错误回绕读取 `2025-01-01`。
- **输入**：截取至 `2025-12-31` 为止的全年附件格式数据（`2025-12-31` 为周三，数据末尾无 `2026-01-01` 记录），在 `2025-12-31` 运行 Q2/Q3/Q4 的计划制定与日内滚动控制；并人为将 `2025-01-01`（历史首日）填入极高电价 $p = 999\text{ 元/kWh}$ 的哨兵值。
- **期望输出 / 可核查性质**：
  1. 程序在 `2025-12-31` 全天及 `23:50-24:00` 执行完毕无 `KeyError`/`IndexError`/`NaN`。
  2. `2025-12-31` 晚间调度**不得受 `2025-01-01` 哨兵电价 $999$ 的异常拉升**（证明程序没有把 `index + 1 mod 365` 错误回绕到年初当成次日实测，在 Q4 下次日晨间部分应从因果同周型历史场景构造）。
  3. `2025-12-31 24:00` 的 SOC 合法落在 $[1200, 10800]$，且保持 H2 终端价值处理行为，不会退化成无终端价值反例下的“每天午夜强制排空至 $1200$”。

### T07：附件 3 预报起点拼接（实测 vs 旧版回退）与整点间线性插值积分（D15）

- **测试目标**：验证预报整点之间的**线性插值 + 10 分钟区间积分**，以及发布时刻起点在“已到达实测”与“未到达回退旧版预报”两种情况下的处理。
- **输入**：考察 `12:00` 版光伏预报的第一个小时 `[12:00, 13:00)`：
  - 旧版（`06:00` 版）对 `12:00` 整点（即预报 6 小时）的预报功率为 $4800\text{ kW}$。
  - `12:00` 版的 `预报1小时`（即 `13:00` 整点）为 $6000\text{ kW}$。
  - 情形 (a)：`11:50-12:00` 实测已到达，功率为 $5400\text{ kW}$。
  - 情形 (b)：`11:50-12:00` 实测尚未到达（缺失/不可用标志）。
- **期望输出 / 可核查性质**：
  1. **情形 (a)**：`12:00` 起点取实测 $5400\text{ kW}$。线性插值在 `[12:00-12:10, ..., 12:50-13:00]` 6 个区间上的平均功率分别为中点值 $[5450, 5550, 5650, 5750, 5850, 5950]\text{ kW}$，对应电量 $[908.3333, 925.0000, 941.6667, 958.3333, 975.0000, 991.6667]\text{ kWh}$，小时积分总量为 $(5400+6000)/2 = 5700.0\text{ kWh}$。
  2. **情形 (b)**：`12:00` 起点必须回退取旧版预报 $4800\text{ kW}$（**绝不得用 $0\text{ kW}$ 填充**！）。6 个区间平均功率 $[4900, 5100, 5300, 5500, 5700, 5900]\text{ kW}$，小时总量为 $5400.0\text{ kWh}$。
  3. **防错点**：若误用右端点采样（`5500, 5600, ..., 6000`），情形 (a) 小时总量会偏高为 $5750\text{ kWh}$。主路线线性积分必须严格区分于“阶梯插值敏感性分析”。

## 二、退化与解析基准情形（T08–T15）

### T08：退化情形——恒定电价且无多余光伏时，Q1 储能严格零动作

- **测试目标**：验证 $0.9 \times 0.9 = 0.81 < 1$ 的能量损耗下，无价差且无富余光伏时储能不发生任何无谓充放。
- **输入**：144 时段 Q1 问题，电价恒为 $p_t = 0.5\text{ 元/kWh}$；所有时段均有 $0 \le G_t \le L_t$（例如夜间 $L_t=100, G_t=0$，白天 $L_t=100, G_t=20\text{ kWh}$）。分别运行“$S(0:00)$ 自由”与“$S(0:00)=6000$”。
- **期望输出 / 可核查性质**：
  1. 所有时段 $c_t = 0, d_t = 0$（SOC 全天恒定不变），$q_t = L_t - G_t$。
  2. 总费用 $= 0.5 \sum_{t=1}^{144}(L_t - G_t)$，且“$S(0:00)$ 自由”与“$S(0:00)=6000$”的最优费用完全相等。

### T09：退化情形——Q1 套利效率临界阈值 $1/0.81$ 与不售电截断 $q_t \ge 0$

- **测试目标**：验证峰谷电价套利门槛 $p_{\text{high}}/p_{\text{low}} > 1/0.81 \approx 1.234568$ 以及禁止倒卖电网（$q_t \ge 0$）对放电量的硬约束。
- **输入**（2 时段日循环 Q1，$S_0 = S_2$，$G_1 = G_2 = 0$，$L_1 = L_2 = 100\text{ kWh}$，$p_1 = 0.81\text{ 元/kWh}$）：
  - 子情形 (a)：$p_2 = 0.99\text{ 元/kWh}$（$p_2/p_1 = 1.2222 < 1/0.81$）。
  - 子情形 (b)：$p_2 = 1.20\text{ 元/kWh}$（$p_2/p_1 = 1.4815 > 1/0.81$）。
- **期望输出 / 可核查性质**：
