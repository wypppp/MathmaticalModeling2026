- S01 三阶段流程：计划形成（业务部门统筹）→ 上报人员调动请示获批 → 实施；本题建模对象是第一、二阶段的产物，第三阶段只作为时间/资源可行性的物理约束。【F附1-一-1】
- S02 计划形成含三项内容：需求统筹（合并减批次）、路线与实施时间规划、定量化评估；三者分别对应 P1/P2 与 P3/P4 的不同侧重。【F附1-一-1】
- S03 决策变量族 A（统筹层）：需求行 → 执行需求单位的再指派 `x[需求行, 执行单位, 批次]`，以及批次是否保留 `y[原批次]`。【F题面-P2；F附1-一-1-(1)】

## §2 目标函数（逐问，标出处）

- O-P1 无优化目标，任务是"分析附件3 计划的形成过程 + 定义合理评价指标 + 评估统筹效果"；评价指标须自定义并给定义式。【F题面-P1】
- O-P1-a 效果侧指标（原题列举，非穷举）：批次数、总里程、出动人员数、车辆数、代领代交货物数量 的前后变化。【F附1-一-1-(3)】
- O-P1-b 效果侧还须含"执行单位代领代交任务的均衡性"。【F附1-一-1-(3)】
- O-P1-c 风险侧指标（原题列举）：批次数、目标仓库到达总次数、出动车辆数、车辆载货行驶总距离、人员调动执行总时长。【F附1-一-1-(3)】
- O-P2 主目标：总调运批次数量尽可能少（字面为唯一显式优化方向）。【F题面-P2】
- O-P2-a 次目标/权衡项：代领代交货物总量与总批次的"平衡"→ 必须给出权衡机制（加权/ε-约束/Pareto），不能只最小化批次而无视代领量。【F题面-P2】
- O-P2-b P2 显式**不考虑实施时间** → 时间窗、日历、仓库日容量在 P2 中不建模。【F题面-P2】
- O-P2-c P2 交付：附件6 + 正文附表2 四指标（总批次、总车数、总人数、代领代交等效车数）。【F题面-P2；F附5-附表2；D附6】
- O-P3 三目标：载货车辆总行驶距离 ↓、人员调动执行总时间 ↓、实施时间与提报时间一致性 ↑（偏离总天数 ↓）。【F题面-P3】
- O-P3-a P3 的需求分配**冻结为 P2 的解**（"针对问题2得到的货物调运计划"）→ P3 只优化路线与时间，不得重新统筹。【F题面-P3】
- O-P3-b P3 交付明细必含：各批次梯队实施时间、到达各仓库时间、接领送交种类及数量、装卸载等效车辆数、离开仓库时间。【F题面-P3】
- O-P3-c P3 交付：附件7 + 正文附表3 四指标（人员调动总时间、开始时间偏离总天数、总里程、载货车辆总行驶距离）。【F题面-P3；F附5-附表3；D附7】
- O-P4 四目标：总批次 ↓、载货车辆总行驶距离 ↓、人员调动执行总时间 ↓、时间一致性 ↑；**从附件4 原始需求重新统筹**（不冻结 P2）。【F题面-P4】
- O-P4-a P4 新增两个关注点：代领代交任务"均衡性"、各批次到达目标仓库数量的减少（→"批次-仓库对"数）。【F题面-P4；F附2-7】
- O-P4-b P4 交付：附件8 + 正文附表4 十指标（附表2 四项 + 附表3 四项 + 均衡性(自定义) + "批次-仓库对"数）。【F题面-P4；F附5-附表4；D附8】
- O-P4-c P4 必须给出与 P3 方案的**定量化**比较评价，不能只文字描述。【F题面-P4】
- O-M1 载货车辆总行驶距离 = Σ_批次 L̄，其中 L̄ = Σ_i s(w_i)·L(w_i) / Σ_i s(w_i)（image2 `[回查]`）→ 这是**加权平均距离之和**，不是车·公里，禁止实现成 Σ s·L。【F附1-二-14、15】
- O-M2 人员调动执行总时间 = Σ_批次 占用自然日数（天），不是人·天、不是车辆工时。【F附1-二-12】
- O-M3 时间一致性度量 = Σ_批次 |实施开始日 − 提报开始日|（附表3/4 名为"实施开始时间偏离提报开始时间总天数"）→ 只算开始日，不算结束日。【F附5-附表3、附表4】
- O-M4 "批次-仓库对"= 结果中 (批次号, 仓库名) 序对去重计数，示例 (1,WF)；同批次重复访问同仓库计 1。【F附5-附表4 注】
- O-M5 均衡性为自定义指标，但语义被限定："帮别人的同时也被别人帮"→ 应度量**双向性**，而非仅任务量方差。【F附2-7；F附5-附表4】
- O-M6 总里程 = Σ_批次 驻地→…→驻地全段路程和（含空载段、含去队属仓库装货段、含拆分子梯队的各自行驶段）。【F附1-一-3】

## §3 硬约束清单（每条标出处）

- C01 每批次到达目标货物仓库数 ≤ 4（按 S13 口径计数）。【F附2-1】
- C02 每批次运输车辆总数"因代领代交增加的数量" ≤ 3 台（增量口径，非绝对车数）。【F附2-2】
- C03 单批次行驶总里程"一般不超过" 2000 km → 措辞为软，默认作硬约束处理并单列假设（见 A03）。【F附2-3】
- C04 顺带原则：执行代领代交时，每支需求单位的调运批次数不增加，且一批次中目标仓库数量不增加。【F附2-4】
- C05 就近原则：执行方与被代方**共用队属仓库**，或**任意一方驻地与另一方可用队属仓库**距离 ≤ 150 km（"可用"含附表1 共用列）。【F附2-5 第1子条；F附1-附表1】
- C06 就便-代领①：共用队属仓库 且 被代领货物所在仓库 ∈ 执行方目标仓库集。【F附2-5 代领①】
- C07 就便-代领②：不共用 且 被代领货物所在仓库 ∈ 执行方目标集 且 被代方队属仓库 ∈ 执行方目标集。【F附2-5 代领②】
- C08 就便-代领③：不共用、货所在仓 ∈ 执行方目标集、被代方队属仓 ∉ 执行方目标集 → 货卸到执行方队属仓，条件 dist(被代方驻地, 执行方该队属仓) ≤ 150 km。【F附2-5 代领③】
- C09 就便-代领④：不共用、货所在仓 ∈ 执行方目标集、被代方队属仓 ∉ 执行方目标集，但**执行方队属仓 ∈ 被代方某批次目标集**，且**被代方该批次实施时间晚于执行方代领批次实施时间** → 货暂存执行方队属仓，被代方后续自取。【F附2-5 代领④】
- C10 就便-代领⑤：不共用、货所在仓 ∈ 执行方目标集、被代方队属仓 ∉ 执行方目标集，但 dist(执行方驻地, 被代方队属仓) ≤ 150 km **且执行方需为被代方代交** → 执行方额外访问被代方队属仓，里程增加。【F附2-5 代领⑤】
- C11 就便-代交①：共用队属仓库 且 送达仓 ∈ 执行方目标集。【F附2-5 代交①】
- C12 就便-代交②：不共用 且 dist(执行方驻地, 被代方队属仓) ≤ 150 km 且 送达仓 ∈ 执行方目标集。【F附2-5 代交②】
- C13 就便-代交③：不共用 且 被代方队属仓 ∈ 执行方目标集 且 送达仓 ∈ 执行方目标集（原文此处写"被代领货物送达的仓库"，疑为"被代交"笔误 `[回查]`）。【F附2-5 代交③】
- C14 特别约定：U9 的调运在符合就近就便前提下由 U6 代领代交（U6/U9 共用 WP，就近自动成立）。【F附2-6；F附1-附表1】
- C15 均衡性原则（软）：代领代交任务量尽量均衡且双向。【F附2-7】
- C16 所有批次实施时间必须在第二季度内完成：4/1 ≤ 开始日，结束日 ≤ 6/30。【F附2-8】
- C17 开始日不得早于提报开始时间 7 天（含）以上 → 字面推导 **开始日 ≥ 提报开始日 − 6 天**（早 6 天合法、早 7 天违规）；边界见 A05。【F附2-8】
