## 0. 全局结构判断（先看整体）

**Q3/Q4 的时间几乎全部花在走路上。** 停下来测一次只要 5–6 s，相当于走 25–30 m。而路线规划得好不好，相差的是上千米。所以：
- 定位精度不是瓶颈。顺路停下来补测一次，几乎不额外花时间（见 Q3-S3）。
- 真正的优化对象是**总路径长度**，它由两部分构成：①为"证明某频道无源"必须跑的覆盖巡回；②访问每个源的路径。
- 两者可以合并：覆盖站点上的一次扫频，同时完成"发现、交会、排除"三件事。

**四问是一条链。** Q1 给出定位区域和清除判据（F1：最小覆盖圆，下称 MEC），Q2 回答"第二个测点放哪"，这两个结果直接成为 Q3/Q4 的子程序。论文叙事应当按这条链来组织。

## Q1 定位区域与直径

### 结构分析
- 每个楔形（半角 1°，对 ±1.005° 同样成立）= 两个闭半平面的交，再加上"在测点前方"这个半平面 → k 个测点给出 3k 个半平面的交，结果是**凸多边形**，可能为空，也可能无界。【证】
- 凸多边形的直径一定在两个顶点之间取得。【证】
- **Q1b**：按 E4，判据为"所有顶点 X 都满足 (X−A)·(X−B) ≤ 0"。
  - k ≥ 3：按 Jung 定理，可以构造接近等边三角形的区域，它不能被以直径为直径的圆覆盖。【待】需要给出具体构造
  - **k = 2 时也存在反例。**【数】20 万次随机试验中，找到 (X−A)·(X−B)/D² 最大为 **+0.0177**（大于 0 即覆盖失败）。反例构型：交会角约 88.5°，两个测点到源的距离都约 960–990 m。区域接近正方形，但两楔形的边不平行（略呈梯形），于是有一个顶点落到圆外，MEC 半径约为 0.517 D。
  - 推论：**即便是 k = 2，"直径 ≤ 40 m"也不能保证清除成功**，这进一步支持 F1。
  - 论文的亮点可以写成：k = 2 时，覆盖失败的条件可以表示为交会角和距离比的函数，能给出解析刻画。

### 方向
| 组 | 方向 | 说明 |
|---|---|---|
| 精确几何 | 1a | 半平面交（O(k log k)）加旋转卡壳（O(m)）。标准做法，复杂度最优 |
| 精确几何 | 1b | 在大包围盒上逐个半平面裁剪凸多边形，复杂度 O(k²)；再对所有顶点对暴力求最大距离。简单、稳健，**建议作为基线和检查器** |
| 优化表述 | 1c | 用支撑函数表示：直径 = max_θ [h(θ) + h(θ+π)]，用 LP 求支撑值。可以作为交叉验证 |
| 证明/反例 | 1d | k = 2：扫描参数空间（交会角、距离比、误差符号），找到覆盖失败区域的边界并给出解析表达式；k ≥ 3：构造性反例 |

退化情况统一处理：空集 → 报告观测不相容；无界 → 直径为 ∞；点或线段按定义处理。

## Q2 第二测点

### 结构分析
- 可能的源位置 P 是一条细长楔形：长度 ≤ 1500 m，并被 1800 m 的圆截断；在距离 r 处横向宽度约 2r·tan1°。
- 测得第二个示向度后，定位区域近似为一个平行四边形。两条边分别约为 w₁/sinφ 和 w₂/sinφ，其中 wᵢ = 2rᵢ·tan1°，φ 为交会角。
- 一对矛盾：要让最坏情况下的直径小，S₂ 应当靠近 P、且与第一条射线正交；但 S₂ 又必须对 P 中**所有点**都满足 5 < d ≤ 1000，所以不能离 P 的任何一端太远。最坏情况出在 P 的两个端点上。
- 因此最优 S₂ 应位于 **P 中段的侧方**，是一个 minimax 问题。

### 方向
| 组 | 方向 | 说明 |
|---|---|---|
| 解析近似 | 2a | 用平行四边形公式，把最坏直径写成 S₂ 位置的函数；用小角近似求解析最优点。可解释性强 |
| 数值精确 | 2b | 在候选区域上做网格搜索加局部细化；对每个候选 S₂，枚举 P 中的源位置和误差极值，求精确的最坏直径。**作为主计算和检验** |
| 指标变体 | 2c | 改用均匀先验下的期望直径作为敏感性对比，说明结论对指标选择是否稳健 |
| 面向 Q3 | 2d | 把移动时间纳入考虑，研究"定位精度 vs 时间"的帕累托前沿。只作讨论，不计入 Q2 主结论（D5） |

候选区域的输出形式：可行域（E5）中，最坏直径 ≤ 阈值 τ 的子集。画出 τ 取不同值时的等值线族。

## Q3 全向搜索清除

### 结构分析
1. **排除覆盖。** 每个没有找到源的频道，都需要一组测点，使圆内每一点到某个测点的距离都 ≤ 995 m（F2 裕度）。这是"用半径 995 的圆覆盖半径 1800 的圆"的问题，比值为 1.809。
   - 【待】已知最优圆覆盖结果（凭记忆）：6 个圆能覆盖的最大比值约为 1/0.5559 ≈ 1.799，7 个圆可以达到 2.0。如果这个数值准确，**6 个站刚好不够，至少需要 7 个**。出题人很可能是刻意把区域半径定为 1800 的。必须在 G3 用数值验证。
2. **扫频成本。** 在一个站把未解决的频道扫一遍，每个频道约 6 s。一旦某个频道的源被清除，此后任何站都不必再扫它。
3. **顺路补测几乎免费（S3）。** 走向某个源的路上，在离它约 200–300 m 处停一下测一次（5–6 s，不绕路），横向误差就只有约 ±5 m，MEC 很容易压到 19.5 m 以内。所以每个源的定位成本大约只是一次停顿。
4. **E1 的作用。** 第 16 次成功清除后即可停止，但这只在 N = 16 的案例中起作用。
5. **下界。** 一种是神谕下界：已知所有源的位置时，从原点出发访问所有源的 TSP（越权信息，只作为参照）。另一种更紧的"合法下界"：覆盖巡回加 TSP 的某种组合，需要再推导。

### 方向
| 组 | 方向 | 说明 |
|---|---|---|
| 静态规划 | 3a | **基线**：固定 7 个站（中心 1 个加外环 6 个），按巡回顺序在每站扫描所有未解决频道；扫完后交会定位，再按 TSP 顺序逐个清除 |
| 静态规划 | 3b | 用 Gurobi 求解**覆盖巡回问题**：先离散化候选站位，MILP 同时选出覆盖站并排好巡回顺序，使路径最短。这些可以离线预先算好，因为开局时没有任何信息 |
| 在线交织 | 3c | **主路线候选**：沿覆盖巡回前进；每到一个站就更新各频道的可行域；一旦某个源的 MEC ≤ 19.5 m，或者顺路补测一次即可达标，就用"最便宜插入"把清除点插进当前路线 |
| 在线交织 | 3d | 滚动重规划：每发生一个事件（发现源、清除、排除），就对剩余站点和待清除源重新求一次小规模 TSP 或覆盖问题 |
| 信息价值 | 3e | 贪心选择下一个动作，使"信息增益 / 耗时"最大。最灵活，但计算重、难以证明保证性，只作为挑战路线 |
| 反常操作 | 3f | **盲清代替补测**：当 MEC 落在 (19.5, ~40] m 时，用若干个 20 m 的圆去覆盖可行域（集合覆盖），逐个尝试清除。每次 3 s 加几米移动，可能比补测更省时间 |
| 反常操作 | 3g | **按频道选择性扫频**：到站后只扫"本站能新增覆盖"或"本站能提供有用交会"的频道，而不是把未解决频道全扫一遍 |

## Q4 混合（定向）

### 结构分析
1. **排除条件变强**（E2）：圆内每一点 x，都必须落在它 995 m 邻域内各 no_signal 测点的凸包里。
2. **三角网格就是充分构造。**【证】把站点排成**边长 ≤ 995 m 的三角网格**。任意一点 x 都落在某个闭三角形内，三个顶点到 x 的距离都 ≤ 边长 ≤ 995 m；x 是三个顶点的凸组合，所以对任意朝向 u，至少有一个顶点满足 u·(p−x) ≥ 0（落在边界上也成立）。这比 GPT G1 稿中的 600 m 方网格稀疏得多。粗略估计，覆盖到圆外大约需要 **20 个站**，而 Q3 只要 7 个。
3. **圆外站点不可缺少**：区域边缘的点必须被包进三角形里，这正对应 H 的发现。
4. **沿示向度逼近不会出覆盖区。**【证】测点 S 在源的覆盖半平面内，从 S 到源 x 的线段 x + t(S−x)（t ∈ [0,1]）满足 u·(p−x) = t·u·(S−x) ≥ 0。
   - 【待】例外：当 S 接近半平面边界、又叠加 ±1° 误差时，靠近源的一段可能擦进盲区，需要量化这个风险。
5. **测得 no_signal 本身就是信息**：在已知源附近（1000 m 内）测得 no_signal，说明该点在盲区，可以约束源的朝向（这是 H 的直觉）。
6. **成本估计**：设有 4–10 个空频道，每个都要在约 20 个站上各扫一次，扫频约 500–1200 s；巡回路径约 20 km，约 4000 s。所以 Q4 的总时间大约是 Q3 的 2 倍。

### 方向
| 组 | 方向 | 说明 |
|---|---|---|
| 静态规划 | 4a | **基线**：边长 ≤ 995 m 的三角网格（含圆外一圈）加巡回路线；每站扫描未解决频道；对定向源用"沿示向度逼近 + 小偏角补测"来定位 |
| 静态规划 | 4b | 用 Gurobi 求最少站点或最短巡回：约束为"每个离散点都落在某个三角形内，且三角形各边 ≤ 995 m"（更一般地，可以直接用凸包条件）。网格不一定是最优的 |
| 在线交织 | 4c | 同 3c，并加入定向源专用的定位子程序：第二测点只选在已知处于覆盖区的一侧，即靠近第一条射线、小偏角的位置 |
| 在线交织 | 4d | 按频道剪枝：频道一旦解决，就从后续所有站的扫描列表中删除；随着频道陆续解决，后半程巡回的成本会显著下降 |
| 反常操作 | 4e | 盲清（同 3f）。在 Q4 中更有价值，因为 clear 不受盲区影响，近距离时可以不再测向 |
| 自适应排除 | 4f | 不预设网格，而是在线维护每个空频道"尚未排除的位置 × 朝向"集合，每次选择排除面积 / 耗时最大的下一个站。理论上更省，但实现和证明都很难。作为挑战路线 |
