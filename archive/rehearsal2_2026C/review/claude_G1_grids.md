## N3 信息使用审计

**共识解法：** 用历史数据预测 L、G → 每天 0:00 求解一个场景 LP 或报童模型，得到 q → 实时规则调度储能 → Q3 在 6/12/18 点用新的光伏预报重新优化 → Q4 用历史电价预测。

| 信息 | 共识是否用到 | 可能藏着什么 |
|---|---|---|
| I03 当天已过去时段的实际值 | **通常不用**（共识只用新的预报） | **F5：Q3 调整时，负载实测的价值可能大于新光伏预报的价值。** 分析题要把这两种价值拆开 |
| I04 18:00 版预报 | 只用于当天 18–24 时 | 18:00 之后光伏≈0，当天用处很小；它对次日的信息也会被次日 0:00 的新版覆盖 → **推测 18:00 版几乎没有价值**【待】，可以作为分析题的结论候选 |
| I06 储能参数 | 作为约束使用 | 9.6 MWh 对日级误差 F4 → 储能只是一个**部分缓冲**；"保留多少 SOC 作为备用"与"套利"之间存在权衡 |
| I07 0.5 / 1.5 | 只用于计费 | K05 给出 0:00 计划的最优分位数，这是一个**可证明的结论** |
| I08 4 个日期 | 只用于出表 | 季节性 → 预测模型要按季节建模 |
| I10 表 4 示例 | 只用作格式参考 | S22：紧急购电由午后光伏骤降引起 |
| I01 + I06 | 套利 | F1：价比 3.76，套利是主要收益来源；低价在 0–6 时、高价在 18–21 时 → 每天大约一个充放循环 |

## N4 问题之间的桥

| 桥 | 洞察 |
|---|---|
| B1 Q1 → Q2 | Q1 的确定性最优解（完美信息）就是 Q2 的"神谕下界"结构；Q2 和它的费用差，就是不确定性的代价 |
| B2 Q2 → Q3 | 关掉 Q3 的调整，就得到"Q2 + 光伏预报"；这样可以把"预报的价值"和"调整的价值"分开 |
| B3 Q3 → Q4 | 电价不确定性叠加在净负荷不确定性之上；如果两者相关，就会互相放大风险 |
| B4 Q1 → Q2–Q4 | **Q1 稳态解中的 0:00 储电量，可以作为 Q2–Q4 日末 SOC 目标或终端价值的锚点**，省去复杂的跨日价值函数 |
| B5 | Q4-2 严格沿用 Q2 的信息条件（不使用附件 3） |
| B6 | 分析题 = B2 的消融实验，再加上 I03 的负载实测价值 |

## N5 约束松紧表

| 项 | 洞察 |
|---|---|
| K01 | 9.6 MWh 可用容量：套利每个循环约可转移 7.8 MWh（×0.81），而日级误差可达数万 kWh → 备用和套利争抢同一份容量 |
| K02 | 每时段 833 kWh，大于单时段误差的标准差 198（F3）→ **功率不是瓶颈，容量才是** |
| K03 | 往返 81%，门槛价比 1.235，远小于 3.76 → 套利显著；效率改为往返 90% 时套利更强 |
| K04 | 无储能、单时段时，临界比为 0.8；有储能时，多买的电可以充进电池，代价从 p 降到大约 p×(1 − 0.81×后续使用价值 / p)，最优分位数会下降【推】 |
| **K05** | **【证】读法 A：** 设 0:00 的计划量为 q，调整时得知的需求为 x。x < q 时，多付 0.5p(q − x)；x > q 时，多付 0.5p(x − q)。**两边对称 → 对能在调整时刻之后执行的时段，0:00 计划的最优值是 x 的中位数**。**读法 B：** 少买时多付 0.5p，多买时多付 p → 最优值是 **1/3 分位数**。所以 **D8 的读法会把 0:00 计划从中位数变成 33% 分位数**，这是一个可证明、且影响结果的结论。0:00–6:00 的时段在调整之前就已执行，仍然适用 K04 |
| K06 | 18:00 版的价值很小（I04）；6:00 和 12:00 版覆盖了光伏的主要时段 |
| K07 | 1 月热身期结束后，2.1 的 SOC 取决于策略本身 |
| K08 | 整点预报插值后会低估 10 分钟尺度的波动 → 需要额外的功率或容量备用；不过 K02 表明功率很充足 |
| K09 | Q1 的日循环条件会把 SOC 锁在稳态水平；Q2 如果不加日末约束，就会出现短视放空 → 需要 B4 的锚点 |

## 最重要的 5 条

1. **K05：** 在 D8 的两种读法下，Q3 的 0:00 计划分别取**中位数**和 **33% 分位数**。这是一个可证明的结论，也给了 D8 敏感性分析实际意义。
2. **F5 + U1×O5：** 日内误差的相关系数为 0.97 → Q3 调整的价值主要来自**当天负载与光伏的实测**，不只是新的预报。分析题要把两者拆开衡量；Q2 的储能实时调度也应当用上这一点。
3. **F4 + K01：** 日级误差远大于储能容量 → 储能只是部分缓冲；**备用 SOC 与套利是核心权衡**。
4. **B4：** 用 Q1 稳态解的储电量作为 Q2–Q4 的日末 SOC 锚点，简单且可解释。
5. **I04 / K06：** 推测 18:00 版预报几乎没有价值 → 可以作为分析题的一个可验证结论。
