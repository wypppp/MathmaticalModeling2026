# Claude 独立路线稿（C 题 G2）

> 独立稿：写作时未读 GPT 和第三方的 G2 稿。依据 `spec.md` v2（含 G2 前的数据更正：低负载日为周五和周六）。

## 0. 全局结构判断

1. **四问共用一个回测器。** 时钟、储能台账、因果执行顺序（spec §3.2）、结算、输出写入，四问都一样。先把回测器做成独立模块，并配一个独立检查器，Q2–Q4 只替换"预测器 + 计划器 + 执行策略"。这是工程闭环的关键。
2. **不确定性的主要来源是"周型 + 季节 + 光伏天气"。** 周型几乎可以确定性地预测（周五、周六为低负载日）。剩下的误差量级与储能容量相当（全天 p95 约 11 MWh，储能 9.6 MWh）→ **储能能吸收大部分误差，但做不到全部**。所以"备用 SOC"和"套利"之间的权衡是真实存在的。
3. **价比 3.76，套利是主要收益来源**：0–6 时低价充电，18–21 时高价放电，每天大约一个循环。
4. 成本分解，各问都按这个口径报告：**总费用 = 神谕下界 + 预测误差的代价 + 策略次优的代价**。神谕下界指当天实际值全部已知时的最优费用。

## Q2 日前计划 + 实时储能（主体）

### 子模块

| 模块 | 方向 | 说明 |
|---|---|---|
| **预测** | P0 | 上周同一天（基线，单时段误差标准差 80） |
| | P1 | 按星期几分组，近 k 周加权平均，并做季节趋势校正 |
| | P2 | 回归或梯度提升：特征为星期几、日序、滞后 7 天、滞后 1 天的同类日；L 和 G 分别建模，**严格滚动训练（只用 d−1 天及以前的数据）** |
| **场景** | S1 | **整天残差块自助法**：从历史中按"同周型、相近季节"抽取**整天**的残差曲线，叠加到点预测上，保留日内相关和 L、G 的联合关系 |
| | S2 | 分位数回归直接生成分布（对照用） |
| **计划** | C0 | 点预测 + 确定性 LP（基线） |
| | C1 | 报童启发式：每个时段取净负荷分布的 θ 分位数，θ 作为超参数，在 1 月或滚动窗口上调优 |
| | **C2** | **两阶段随机规划（主路线）**：第一阶段决定 q（144 个变量）；第二阶段对每个场景决定 c、d、e、w；最小化期望费用加日末 SOC 价值。场景数 50–200，LP 规模可控 |
| | C3 | CVaR 或鲁棒版本（敏感性分析） |
| **执行** | X0 | 规则：按计划的 SOC 轨迹走，偏差先由储能吸收，必要时紧急购电 |
| | **X1** | **滚动 MPC（主路线）**：每个时段用"已观测前缀 + 剩余时段的条件场景"重解一次小 LP，只执行当前时段的 c、d。每天 144 次，全年约 5 万次小 LP，可以承受 |
| | X2 | 线性决策规则：c、d 按观测偏差的仿射函数决定（可解释，作对照） |
| **日末** | T1 | 锚定 Q1 稳态下的 S(0)（简单） |
| | T2 | 日末 SOC 的边际价值取 Q1 的对偶价格 |
| | T3 | 滚动视界延长到次日早上（例如 30 小时），只执行当天部分 |

**注意：** C2 第二阶段对每个场景"已知全天"，是**偏乐观的近似**。真实执行由 X1 完成，所以报告的费用必须是**因果回放**的结果，不能用 C2 的目标值代替。

## 差异化点（论文卖点候选）

1. **数据发现：低负载日是周五和周六**，不是日历上的周末。直接用日历标签的队伍会系统性地预测错误。
2. **E2 不调整区间定理**，配合数值验证；并展示 D8 两种读法下的策略差异。
3. **成本分解**：神谕下界、预测误差代价、策略代价。
4. **整天残差块场景**：同时保留日内相关和 L–G–p 的联合关系，并通过消融实验与"独立采样"对比。
5. **Q3 分析题的两类价值分解**，配合按提前期统计的误差曲线。
