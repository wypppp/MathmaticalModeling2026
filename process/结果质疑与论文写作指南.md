# 结果质疑（G5）与论文写作（G6）指南

> 依据：4 篇 2026 国赛优秀论文——B1、B2（干扰源定位）、C1、C2（微网购电）——以及两次演练的教训。
> 来源标注：[B1][B2][C1][C2] 表示该做法在哪篇论文中出现过。
> **核心方法：论文先行、证据驱动。** G2 定下路线后，立刻写出摘要草稿和章节骨架，数字先用占位符；由此倒推出每个结论需要哪些证据（实验、检验、图表），形成证据清单；G3–G5 按清单逐项产出、逐项填回。这样可以避免"做完了才发现缺一个关键对照"。

---

## A. 4 篇论文的共性（"获奖论文长什么样"）

| 共性 | 表现 |
|---|---|
| 摘要里全是硬数字 | 每一问都写出具体数值：费用、比例、站数、覆盖率、信息价值占比 [B1][B2][C1][C2] |
| 每一问围绕"猜想 → 证据链"展开 | 先提出核心猜想，再用"求解 → 对照 → 敏感性"验证 [C1] |
| 三方并列 | 完全信息下界 / 基线 / 本文方法 [C1][C2]；无储能基线 B0 [C1] |
| 先做约束残差校验 | 平衡残差 1.4×10⁻¹² [C1]；9477 个网格单元全部检验、未决为 0 [B1]；25800 个单元无遗漏 [B2] |
| 用理论值校验数值 | 报童理论分位数 0.80 与数值扫描一致 [C2]；储能修正后的理论区间 [0.80, 0.955] [C1] |
| 敢报告"反直觉"或"不利"结果 | 预测更差、但分位选得对的策略反而更省钱 [C1]；滚动选参比固定参数更贵，并给出原因 [C1] |
| 有命题与证明 | 等边三角形反例、站数上界、覆盖完备性命题 [B1] |
| 每章有小结；全文末尾有评价、局限与推广 | [C1][C2][B1] |
| 声明结论的适用范围 | "不对超出数据范围的情形作推断" [B2] |
| **AI 工具使用声明** | 单列一节，说明用途；详细记录放在支撑材料中 [B1] |
| 参考文献少而真实 | 例如 CGAL 文档、经典算法论文 [B1] |
| 篇幅约 30 页，图表密度约每 1–2 页一张 | [B1][B2] |

## B. G5 结果质疑清单（逐项打勾；做不到的要在论文中说明原因）

### B1. 正确性
- [ ] **约束残差报告**：给出最大平衡残差、SOC/边界越界量、互斥违例数，写进论文 [C1][B1]
- [ ] **独立复算一致**：GPT 独立实现得到的关键数字与主结果一致（我们的流程）
- [ ] **理论值与数值一致**：凡是有解析结果的地方（例如分位数、界、退化情形），数值结果必须与之吻合 [C2][C1]
- [ ] **唯一性诊断**：最优值唯一，但最优解可能不唯一。说明表格中报告的是哪一个解（例如字典序解）[C1]

### B2. 有效性
- [ ] **三方并列**：神谕下界 / 简单强基线 / 本文方法；给出成本分解或信息价值占比 [C1][C2]
- [ ] **参数扫描**：关键参数画出 U 形曲线，标出最优区间，并与理论值对照 [C1]
- [ ] **样本外检验**：参数只用前一段数据（例如 1 月）标定，看结论是否一致；或者滚动选参 [C2][C1]
- [ ] **对照实验**：至少一组"去掉本文关键设计"的消融对照；有反直觉的结论更好 [C1]
- [ ] **显著性**：凡是写"显著"，必须配有检验（例如配对检验、块重采样置信区间、P 值）[C1]
- [ ] **预测校准**（如果用了概率预测）：PIT 直方图、分位覆盖率、pinball 损失 [C1]

### B3. 稳健性
- [ ] **敏感性分析**：龙卷风图覆盖所有关键参数；包括题目口径有争议的那一项（例如效率、初值）[C2][C1]
- [ ] **极端情形**：例如阴天、负载翻倍、最坏误差 [C2]
- [ ] **离群点识别**：找出离群日或离群样本，说明如何处理 [C1]

### B4. 机制解释（加分项）
- [ ] **对偶 / 影子价格**解释决策规则（例如"何时充、何时放"）[C1][C2]
- [ ] **专题分析**：协方差分解、弃光机理、等效循环次数等，回答"为什么" [C2]
- [ ] **信息价值阶梯**：逐级放宽信息，量化每一级的价值 [C1][C2]

### B5. 结果质疑者（第三方）
- [ ] 只给结果表和图（不给代码），让它找出：不合理的数字、缺失的对照、证据撑不起的结论。逐条回应或修正。

## C. 论文写作

### C1. 章节骨架（约 30 页）

| 部分 | 页数 | 要点 |
|---|---|---|
| 摘要 | 1 | 见 C2 |
| 一、问题重述 | 1–2 | 背景、问题、**数据介绍** [C1] |
| 二、问题分析 | 2 | 总体分析 + 各问分析 + **技术路线图**（一张流程图）[B1][C1] |
| 三、模型假设 | 1 | **每条假设附理由**，例如"信息集（因果性）假设""充放电互斥假设" [C2] |
| 四、符号说明 | 1 | 表格，含单位 |
| 五至八、各问的建模与求解 | 每问 4–6 页 | 见 C3 |
| 九、模型检验（可选单列） | 2 | 对照实验汇总、敏感性 [C2] |
| 十、模型评价与推广 | 1 | 优点、缺点、改进、推广 |
| AI 工具使用声明 | 0.2 | [B1] |
| 参考文献 | 0.5 | 少而真实，联网核实 |
| 附录 / 支撑材料 | — | 代码、结果文件、AI 使用记录 |

### C2. 摘要模板

> 第 1 段：一句话说明问题本质和全文框架（"建立了……的统一框架"）。
> 第 2–5 段，每一问一段：**针对问题 X**，建立**<模型名>**，用<方法/关键思想>；**<核心数字结论>**（加粗）；<一句对照或验证>（例如"较基线降低 26.9%""与理论分位数 0.80 一致"）。
> 末段：综合结论 + 适用范围。
> 关键词：4–6 个，与各问的模型名一一对应。

**要求：** 数字与正文、表格、`evidence.md` 完全一致；由人逐句改写，防止雷同、被查重。

### C3. 每一问章节的模板

1. **问题分析**：本问的本质 + **核心猜想**（例如"最优计划应取高分位数"）[C1]
2. **数据分析 / 预处理**：支撑猜想的数据事实
3. **模型建立**：决策变量 → 目标 → 约束（编号公式）；必要时给出命题与证明 [B1]
4. **求解**：算法、求解器、复杂度
5. **结果分析**：表格（按题目要求的格式）+ 图；用对偶或机制解释"为什么"
6. **检验**：残差、理论与数值对照、对照实验、敏感性
7. **本章小结**：3–4 行，回扣核心猜想 [C1]

### C4. 推荐的图

技术路线图 [B1][C1]；决策轨迹图（例如 SOC 曲线）；费用构成堆叠图；参数 U 形曲线 [C1]；敏感性龙卷风图 [C2]；校准直方图 [C1]；几何示意图 [B1][B2]。**全部由代码生成**，文件名登记到 `evidence.md`。

### C5. 表述规范

- 区分**事实、推断与假设**；"显著"必须有检验支撑。
- 题目口径有争议的地方，在假设里写明所选读法和理由，并在敏感性分析中给出另一种读法的结果（演练 2 的 D10 教训）。
- 报告不利结果并给出解释，比隐藏它更加分 [C1]。
- 声明结论的适用范围 [B2]；写清楚局限 [C2][B1]。
- **AI 工具使用声明**：说明用途（题目辅助分析、模型推导讨论、代码调试、图表优化等），详细记录放进支撑材料 [B1]。比赛期间，仓库里的 `review/`、`state.md` 和提交历史本身就是使用记录，按需整理导出即可。

## D. 时间安排（嵌入作战手册的五天节奏）

| 时点 | 写作动作 |
|---|---|
| G2 结束（第 2 天） | **摘要草稿 + 章节骨架 + 证据清单**（数字留占位符） |
| G3–G4（第 2–3 天） | 每完成一个结果就填入对应章节；图由代码生成 |
| G5（第 4 天） | 按 B 节清单逐项打勾；第三方做结果质疑；**当晚完成初稿** |
| G6（第 5 天） | 人改写摘要和核心论证；第三方盲评（①只读摘要并复述 ②按评分要点挑缺陷 ③指出最不可信的 3 处）；数字溯源；格式检查；排版提交 |
